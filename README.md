Titanic Survival Prediction

A Machine Learning project that predicts whether a Titanic passenger would survive or not based on:

* Gender
* Age
* Passenger Class
* Number of Siblings/Spouses
* Fare

How it works

The model learns patterns from historical Titanic passenger data and uses those patterns to predict the outcome for a new passenger.

Prediction: Survived or Did Not Survive

Model Used
Logistic Regression — a classification algorithm used to predict outcomes with two possible results.

Tools
Python • Pandas • NumPy • Matplotlib • Scikit-learn
